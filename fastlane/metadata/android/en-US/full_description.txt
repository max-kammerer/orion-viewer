Orion Viewer is a lightweight and fast viewer of PDF, DjVu, XPS, TIFF and comic books (CBZ, CBR, CB7, CBT) for Android devices, based on the MuPDF and DjVuLibre libraries. It also opens WebP images and Markdown files.

Application features:
• Outline navigation and navigation history
• Links in PDF and DjVu files
• Bookmarks with export and import
• Page navigation by screen taps, configurable tap zones and key bindings
• Text search and selection
• Single word selection by double tap with translation in an external dictionary
• Custom zoom, continuous scrolling with an adjustable gap between pages
• Manual and automatic margin crop, with default margins for new books
• Page layouts and navigation patterns inside a page (left to right, right to left)
• Logical page numbers as printed in the book
• Portrait and landscape orientation, color modes and themes
• Built-in file manager with recently opened files
